pi-rs セッションプレビュー

pi-rs の AgentSession がブラウザ内で動きます。接続先を選んでください。

モデルはこのブラウザ内で動きます。初回はモデルをダウンロードします。WebGPU が必要です。

この PC の Ollama（127.0.0.1:11434）に直接接続します。公開プレビューからは Ollama の接続許可が必要です。

QuantumBox テナントにアクセスできるトークンを入力してください。トークンはこのページのメモリ内だけで使い、保存しません。API の利用料金はテナントに発生します。

macOS では tachyon auth token --tenant-id quantumbox | pbcopy でコピーできます。ページを再読み込みした場合は再入力してください。
